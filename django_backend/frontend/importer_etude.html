Importer une étude déjà réalisée

Pour une étude terminée ailleurs (Google Forms, Kobo…) dont tu as le fichier Excel des réponses : une ligne par personne, une colonne par question. L'application en tire le questionnaire et les fiches. Rien n'est enregistré avant l'étape 3, et l'étape 2 te laisse corriger ce qu'elle a deviné.

1 Le fichier

Si le fichier contient deux questionnaires côte à côte (colonnes en double avec un suffixe), coupe-le d'abord en deux fichiers dans Excel : un fichier = un questionnaire.

2 Vérifier ce que l'application a compris

–lignes de réponses
–questions
–colonnes d'identité

Rôle : une colonne d'identité (prénom, nom, téléphone…) devient le patient ; une question devient une question du formulaire ; ignorer l'écarte. Type : deviné d'après les valeurs — corrige si besoin.
