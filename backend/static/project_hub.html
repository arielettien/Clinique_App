💡 Comment ça marche ?
Le Module 1 (Enquête) sert à collecter des données transversales (enquêtes, dépistages). Quand un patient doit être suivi dans le temps (sur la base de critères cliniques), il est transféré vers le Module 2 (Suivi) où il aura un dossier avec un identifiant unique, des visites planifiées et un suivi longitudinal.
